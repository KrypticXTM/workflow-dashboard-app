# Workflow Dashboard: Window Tiling for Windows

Windows desk that tiles real app windows into a single dashboard.

## Features
- Link Window tiling with theme-colored outline
- Panes that stay put
- 1.2.3: linked windows stay visible while hovering/dragging to link another
- Media panel with play/pause/prev/next/volume/−10s/+10s
- Optional Auto-skip ads toggle on the media panel
- Themes (Canary, Sky, Rose)
- Frameless look

## Install
Download `WorkflowDashboard-Setup-1.2.3.exe` from Releases and run it (per-user, no admin). It installs to `%LOCALAPPDATA%\Programs\WorkflowDashboard`, adds a Start Menu shortcut, and an uninstaller. A portable zip is also available.

Requires the [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0). The installer is unsigned, so Windows SmartScreen may show “Windows protected your PC” — click **More info > Run anyway**.
